# Security

This repository is a Next.js starter for Externa's Public CMS API.

**Do not open a public GitHub issue for security bugs.**

Report vulnerabilities against the Externa application and hosting model via
[`qiick-io/externa-core` SECURITY.md](https://github.com/qiick-io/externa-core/blob/main/SECURITY.md)
(email / private vulnerability reporting as described there).

If the issue is specific to this starter (example code, client wiring), say so
in the report and include the step to reproduce against a local Externa instance.
